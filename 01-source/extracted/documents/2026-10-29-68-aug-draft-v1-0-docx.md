AUGUST RELEASE NOTES | Page 1 of 1
Release Date: 29th August 2026

Note: Items marked with * are critical event and to expedite the critical event, * marked are At Risk.

GLOBALS
Features, Changes & Faults

‘Notify’ mail now get captured in change log.
Added translate and rephrase in notes. 
Added a user ‘Preference’ sub tab in the profile to enable or disable the Rephrase and Translate features.
Added the Customer name to the notification banner after the RMA Number/SN.
Standardized the FBN/FPT Fabrinet values to match the format of other dropdowns and fixed the existing entries.
Fixed an issue with the Change Password feature.

RMA SERVICE OPERATION
Features, Changes & Faults

Fixed search box bug for other roles other than super admin.
Added translate and rephrase in ‘Problem Description’ and ‘Special Instructions’ input field boxes in ‘Product RMA Information’ subtab in ‘Customer Support’ tab.


REPAIR SERVICE OPERATION
Features, Changes & Faults

Added a Highlighting drop-down to highlight values that are not present in Index Management.
Added translate and rephrase in ‘Diagnosis’ and ‘Repair/Test’ subtabs in repair service detail page.
Improved PSR function latency by reducing duplicate AWS calls for supporting files.


FAILURE ANALYSIS RECORD
Features, Changes & Faults

Added ‘Expand all’ in CAPA Plan.
Added gate to Stop FA for approval with overdue capa.
Added translate and rephrase in D2: Failure Description, D3: Containment and D4: Root Cause Investigation subtabs in FAR detail page.
Replaced the FAR hotlots section with RMA Hotlots and QMS Hotlots.
Added search feature in hotlots page. 
Improved Master FA search to include keywords from the Master FA description and Component Part Number.
Fixed an issue where Save did not work after changing the order of hotlots.
Fixed an issue where the dropdown did not close when multiple RMAs were selected on the FAR Hotlots page.
Fixed an issue where sorting by ‘Status’ was not working in the CFAR table.

Product Performance
Features, Changes & Faults
  Product performance scorecard latency improved



FINANCIAL PERFORMANCE
Features, Changes & Faults

Removed P&L section in Executive Scorecard table.
Formatted percentage values to display up to two decimal places.

REPORTING TOOL
Features, Changes & Faults

Fixed an issue with the Bookmark feature in the Reporting Tool.




INDEX MANAGEMENT
Features, Changes & Faults

Added New Quotation POC smartrule rule.
Renamed CUSTOMER POC to RMA creation poc.
The active user’s email will appear in the Email drop-down.
Added ‘Failure Source’ option in CFAR Required smart rule.
FAR creation Smart rule bug.

CUSTOMER REQUEST
Features, Changes & Faults

Added rephrase in ‘Issue Name’ and ‘Issue Description’ input fields in ‘New Customer Request’ tab.

INBOX
Features, Changes & Faults
